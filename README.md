# Python Student Database Management System

A simple Student Database Management System developed using Python.

## Features

- Add student details
- View all student records
- Search students using roll number
- Simple menu-driven interface
- Beginner-friendly Python project

## Technologies Used

- Python
- Data Structures
- Functions
- Git & GitHub

## How to Run

1. Download or clone this repository.
2. Open `student_database.py`.
3. Run the Python file.
4. Select an option from the menu.
